# Security Policy

## Supported Content

This repository primarily contains educational Python scripts and markdown
documentation. There are currently no deployed services, authentication flows,
or production secrets managed in this project.

## Reporting a Vulnerability

If you discover a security issue, please do not post it publicly in an issue.
Instead, contact the maintainer privately and include:

- a description of the issue
- affected files or areas
- steps to reproduce
- the potential impact
- any suggested remediation

Reasonable efforts will be made to review and address legitimate reports in a
timely manner.

## Good Practices for Contributors

- Never commit secrets, API keys, or private credentials
- Do not include personal tokens in code examples
- Keep dependencies minimal if tooling is added later
- Review automation files carefully before expanding CI behavior
